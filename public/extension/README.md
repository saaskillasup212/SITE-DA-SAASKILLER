# Mídia da demonstração

Coloque o poster do vídeo neste diretório com o nome:

`demo-poster.webp`

A URL e os demais dados do vídeo são configurados em:

`src/config/extension.ts`

Enquanto `extensionDemo.videoUrl` estiver vazio, a página mostra a representação
visual da extensão e não carrega poster, iframe ou player.
